How to Install Configs

  1. Download the .txt config file from Discord
  2. Copy the downloaded file
  3. Navigate to your macro's "Settings" folder
  4. Paste into the appropriate subfolder (raids/legends/dungeons) or main Settings folder for custom configs
  5. Open the macro and select your config!
Raids, legends, and portals must start in lobby. Other configs start in-game.
